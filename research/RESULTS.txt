# Monotonic Causal Resolution (MCR)

## 1. Purpose

Monotonic Causal Resolution is a problem-solving method for advancing toward a correct answer without:

- building on unearned premises,
- confusing current resolution with ultimate foundation,
- solving questions that do not advance the active problem,
- descending indefinitely into unnecessary prerequisites,
- or discarding already-earned structure when a later branch fails.

The objective is not speed.

The objective is:

\[
\boxed{\text{maximum justified forward progress with preserved causal provenance}}
\]

The method is designed so that being wrong remains locally repairable.

---

## 2. Foundational Principle

At any finite stage of reasoning, the deepest currently resolved structure is only the current resolution boundary.

\[
\boxed{\text{current resolution boundary} \neq \text{ontological finality}}
\]

An unresolved antecedent may remain unresolved.

It may not be silently promoted into a primitive.

Therefore:

\[
\text{OPEN} \neq \text{FOUNDATIONAL}
\]

and:

\[
\text{unresolved} \neq \text{arbitrary}.
\]

Whatever the correct answer is, it remains constrained by everything already causally and logically earned.

---

# 3. Core Invariants

## I. Causal Provenance

Every load-bearing claim must have an identifiable reason for being accepted.

A claim may be:

- observed,
- derived,
- defined,
- explicitly assumed for a bounded scope,
- or unresolved.

## V. Resolve to Necessity, Not Exhaustion

The existence of an unanswered question does not make that question immediately relevant.

For a proposed next step \(S\), identify its prerequisite set:

\[
P(S)=\{p_1,p_2,\ldots,p_n\}.
\]

Only the resolution required by \(S\) must currently be obtained.

If \(S\) requires:

\[
x>3
\]

and current evidence establishes:

\[
7<x<12,
\]

then the prerequisite is satisfied.

Determining the exact value of \(x\) does not currently advance the active problem.

---

## VI. Branch Sensitivity

For any unresolved question \(Q\), ask:

> Would different admissible resolutions of \(Q\) change the next justified move?

If:

\[
Q=a\Rightarrow S
\]

and:

\[
Q=b\Rightarrow S
\]

for every currently admissible resolution of \(Q\), then resolving \(Q\) further is presently unnecessary.

If instead:

\[
Q=a\Rightarrow S_1
\]

while:

\[
Q=b\Rightarrow S_2,
\]

then \(Q\) is load-bearing and must be investigated before choosing the branch.

Therefore:

\[
\boxed{\text{productive uncertainty}=\text{branch-sensitive uncertainty}}
\]

for the active problem.

---

## VII. Scope Fidelity

A local result must remain local unless additional reasoning earns a broader claim.

These are different statements:

\[
C\Rightarrow D
\]

\[
C\text{ is itself explained}
\]

\[
C\text{ is ontologically primitive}
\]

Proving the first does not prove the second or third.

Every conclusion must preserve the scope under which it was earned.

\[
\boxed{\textbf{Resolve to necessity. Preserve provenance. Checkpoint what is earned. Advance.}}
\]

> **Go only as deep as necessary to justify the next step, but never move forward across an unearned causal gap. Preserve every valid dependency so that a later failure requires only local rollback. # 8. Monotonic Progress

Monotonic progress does **not** mean that the number of accepted claims can never decrease.

A correction may legitimately invalidate previous work.

Monotonicity refers instead to the integrity of the search.

A transition:

\[
K_n\rightarrow K_{n+1}
\]

is monotonic when it does not knowingly preserve invalid provenance and performs at least one of the following:

- extends the validated causal chain,
- reduces branch-sensitive uncertainty,
- removes an unsupported branch,
- repairs a provenance defect,
- establishes a new known-good checkpoint,
- or correctly rolls back structure invalidated by new evidence.

The process must never improve apparent progress by increasing hidden epistemic debt.

---

# 9. Checkpoint Rule

Create a known-good checkpoint whenever the active dependency chain has sufficient support for meaningful continuation.

A checkpoint represents:

\[
\boxed{\text{maximum currently reusable justified structure}}
\]

A checkpoint does not claim ultimate truth.

It says:

\[
\boxed{\text{checkpoint and move forward}}
\]

An unresolved deeper question remains OPEN.

It does not block unrelated progress.

# 13. Search-System Quality

A problem-solving system should be evaluated separately from whether its current answer happens to be correct.

A sound search process:

- preserves provenance,
- identifies its unresolved boundaries,
- exposes assumptions,
- detects contradictions,
- supports local rollback,
- and remains responsive to new evidence.

Therefore:

\[
\text{correct answer}
\not\Rightarrow
\text{sound method}
\]

and:

\[
\text{temporary wrong answer}
\not\Rightarrow
\text{unsound method}.
\]

The stronger measure is:

\[
\boxed{\text{Does the system preserve a valid path by which error can be discovered and repaired?}}
\]

---

# 14. Comparison Between Competing Explanations

When comparing models \(M_A\) and \(M_B\), do not compare only their final conclusions.

Compare their causal ancestry.

If:

\[
M_A:
A\rightarrow B\rightarrow C
\]

while:

\[
M_B:
\boxed{C}\rightarrow D
\]

and \(M_B\) treats \(C\) as primitive without justification while \(M_A\) successfully derives it, then \(M_A\) has greater current causal resolution at that point.

This does not prove \(M_A\) ultimately correct.

# 5. The Active Frontier

At every stage, distinguish between:

### Validated structure

What has already been earned.

### Active frontier

The smallest set of unresolved questions presently preventing the next justified step.

### Deferred frontier

Unresolved questions that exist but are not currently load-bearing.

The method works primarily on the active frontier.

It does not attempt to exhaust the deferred frontier.

---

# 6. Selecting the Next Step

Given current knowledge state \(K_n\), propose candidate step:

\[
S_{n+1}.
\]

Then ask:

### Question 1

What must already be true for \(S_{n+1}\) to be valid?

Construct:

\[
P(S_{n+1}).
\]

### Question 2

Which prerequisites are already sufficiently resolved?

Do not demand greater precision than the next step consumes.

### Question 3

Which unresolved prerequisites could change whether \(S_{n+1}\) is valid?

These form the active frontier.

### Question 4

Can every currently admissible resolution of an unresolved prerequisite still support the same next step?

If yes:

\[
\boxed{\text{advance}}
\]

If no:

\[
\boxed{\text{resolve the branch-sensitive prerequisite}}
\]
