# VLL Rung-1 Mechanism Decision v0.2
## Canonical-path correction after retiring RE-VGSP / GDSP from the forward ladder

### Revision

RE-VGSP and GDSP are no longer treated as presumptive future VDM rungs.

Their correct status in this research program is:

- **historical proxy / ancestry evidence**;
- **optional comparison or ablation reference**;
- **not current architectural authority**;
- **not a default dependency that later VLL rungs must eventually restore**.

This correction matters because the retained runtime itself already demotes them to optional experimental adapters, while the stronger current architecture centers persistent event-folded topology, local walkers, bounded maps, and retained structural state.

### What remains valid from v0.1

The proposed first controlled V1 experiment remains:

\[
V_1 = V_0 + \text{CF04 finite-}\tau\text{ transport}
\]

because that choice does **not** depend on RE-VGSP or GDSP being canonical.

CF04 is being selected as an isolated native transport-law experiment:

- same frozen graph;
- same corpus;
- no topology mutation;
- no semantic changes;
- finite-\(\tau\) transport only;
- diffusive-limit recovery required.

### What is removed from v0.1

The following forward-ladder assumptions are withdrawn:

- “RE-VGSP may be a later rung.”
- “GDSP may be a later rung.”
- any dependency graph that treats SIE → RE-VGSP → GDSP as the canonical future learning/plasticity path;
- any claim that VLL should eventually reconstruct legacy plasticity merely because it existed in FUM/older VDM.

Legacy mechanisms can still explain ancestry and historical experiments. They do not get architectural custody.

# Current canonical topology direction

The strongest retained architectural statement is:

\[
\boxed{
\text{persistent field}
+
\text{persistent event-folded adjacency}
+
\text{local walker traversal}
+
\text{bounded retained maps/state}
}
\]

with no whole-connectome regeneration.

Operationally:

1. \(W\) remains persistent and evolves through native void dynamics.
2. adjacency is retained state rather than a fresh per-tick projection;
3. walkers traverse the active/important local frontier;
4. walker events are the local evidence for structural persistence/change;
5. untouched regions remain untouched;
6. exploration enters through bounded local mechanisms such as Sentinel, not a global graph rebuild;
7. topology changes must remain sparse and event-folded.

This is a stronger architectural constraint than the historical RE-VGSP/GDSP proxy path.

---

# Updated mechanism ladder rule

After CF04, **do not choose the next rung from the old module inventory**.

Reconstruct the next rung from current canonical responsibilities.

Candidate families must be evaluated by role, not legacy name:

- retained local causal state;
- event-folded adjacency persistence/change;
- walker-derived structural evidence;
- slow memory / refractive state;
- territory / boundary / cycle cartography;
- endogenous local modulation;
- Phase/Orthad retained relational custody where causally justified.

A mechanism is eligible only if:

1. its current architectural role is positively established;
2. its prerequisites are already present in the previous rung;
3. it introduces one causally isolatable capability;
4. it does not recreate retired proxy machinery under a new name;
5. it preserves sparse/local execution.

# Historical mechanisms policy

## RE-VGSP

Retain for:

- historical ancestry;
- comparison against older experiments;
- understanding which capability it approximated;
- possible negative-control / proxy-baseline experiments.

Do not assume its exact timing/reward rule belongs in the final VDM architecture.

## GDSP

Retain for:

- historical ancestry;
- comparison with modern structural-action mechanisms;
- understanding which topology-control problem it approximated.

Do not assume a centralized/global prune-grow actuator belongs in the final architecture.

The modern question is not:

> “What replaces GDSP line-for-line?”

It is:

> “What native local causal mechanism now owns the structural responsibility that GDSP once approximated?”

- frozen Rung-0 graph;
- V0 and CF04-V1 side by side;
- \(\tau \to 0\) converges toward V0;
- finite-\(\tau\) transport shows the predicted temporal signature;
